    1はじめに

    1.1　本アプリの概要

    本アプリは、社内の備品を区分ごとに登録・集計し、押印欄付きのA4一覧表をPDF形式で出力するためのアプリケーションです。主な機能は次のとおりです。

    • 部署・設置場所・年度などの区分（ファイル）ごとの備品管理
    • 品名・単価・数量等の登録と、金額の自動計算
    • 管理項目および計算式の追加・変更（例：税込金額、購入日）
    • ファイル単位での出力（PDF・Excel・CSV・画像）

    1.2　用語

    用語意味
    ファイル備品を分類する単位です。画面上では、色の異なるバインダーとして表示されます。
    項目一覧表の列（品名、単価、数量など）です。すべてのファイルで共通です。
    計算項目ほかの項目の値から計算式で求める項目（合計金額など）です。直接入力はできません。
    帳票本アプリが出力する押印欄付きの一覧表です（PDFまたは画像）。
    クリック本書では、マウスによるクリックとタッチ操作によるタップを総称して「クリック」と表記します。

    1.3　利用形態とデータの保存先

    本アプリには次の2つの利用形態があり、データの保存先が異なります。詳細は「9 データの保存と権限」を参照してください。

    • claude.ai上で利用する場合：データは自動で保存され、本アプリを閲覧できる利用者の間で共有されます。
    • HTMLファイル（ローカル版）をブラウザで開いて利用する場合：データは、その端末のブラウザ内にのみ保存されます。

    注意削除したデータは復元できません。重要なデータは定期的に帳票を出力し、保管することを推奨します。

    3ファイルの管理

    3.1　ファイルの作成

    1. ファイル一覧の下にある新しいファイルをクリックします。
    2. ファイル名を入力します（必須）。
    3. 色を選択します。初期状態では、直前のファイルと判別しやすい色（色相環上で反対側にある色）が選択されています。
    4. 作成をクリックします。作成したファイルが表示されます。

    補足帳票のタイトル、会社名・部署名、押印欄の設定は、作成時に表示していたファイルの設定を引き継ぎます。

    3.2　ファイルの切り替え

    ファイル一覧で目的のファイルをクリックするか、画面下部のページ送り（‹ ›）をクリックします。

    3.3　ファイル設定の変更

    ファイル設定をクリックし、次の項目を変更して保存をクリックします。

    設定内容
    ファイル名（必須）ファイル一覧および画面見出しに表示される名称です。
    色28色から選択します。表紙、ボタン、一覧表の見出しの色に反映されます。
    タイトル（任意）帳票の表題です。未入力の場合は「備品一覧表」となります。
    会社名・部署名（任意）帳票の表題の下に印字されます。未入力の場合は印字されません。
    押印欄を入れる帳票の右上に「作成・確認・承認」の押印欄を印字します。

    3.4　ファイルの削除

    1. ファイル設定をクリックします。
    2. 画面左下のこのファイルを削除をクリックします。
    3. 確認メッセージの内容を確認し、削除するをクリックします。

    注意ファイルを削除すると、そのファイルに登録された備品もすべて削除されます。削除したデータは復元できません。

    4備品の登録

    4.1　登録手順

    1. 備品を追加をクリックします。
    2. 各項目を入力します。計算項目（合計金額等）は、入力内容に応じて自動で計算・表示されます。
    3. 登録をクリックします。続けて登録する場合は続けて登録をクリックすると、入力画面を閉じずに次の入力に移ります。

    4.2　入力規則

    • 入力が必須の項目は品名のみです。その他の項目は省略でき、数量は登録後に一覧表で調整できます（5章）。
    • 数値項目は全角・半角のいずれでも入力できます。桁区切りのカンマ、「円」「¥」などの記号は自動的に除去されます（例：「¥12,800」「12800円」は、いずれも 12800 として登録されます）。
    • 登録先のファイルは、入力画面下部のファイルで変更できます。

    5数量の調整・備品情報の修正・削除

    操作手順
    数量の調整一覧表の数量欄の＋または−をクリックすると、1ずつ増減します。数値を直接入力し、Enterキーを押すか欄の外をクリックして確定することもできます。変更は直ちに保存されます。
    修正一覧表の行末にある鉛筆アイコンをクリックし、内容を変更して保存をクリックします。
    他のファイルへの移動修正画面のファイルで移動先を選択し、保存をクリックします。
    削除行末のごみ箱アイコンをクリックし、確認表示で削除をクリックします。やめるをクリックすると取り消せます。

    注意削除した備品は復元できません。

    6一覧の検索と並べ替え

    • 検索：検索欄に語句を入力すると、文字項目（品名、備考等）にその語句を含む備品のみを表示します。絞り込み中は合計行が「合計（n件）」と表示され、表示中の備品のみを集計します。
    • 並べ替え：並び順から、登録順、新しい順、各項目の昇順・降順を選択できます。

    補足出力には、検索条件にかかわらず、そのファイルのすべての備品が選択中の並び順で含まれます。

    7出力（PDF・Excel・CSV・画像）

    7.1　出力手順

    1. 出力するファイルを表示します。
    2. 出力をクリックします。
    3. 形式を選択します。PDFまたは画像の場合は、用紙サイズ画質向きも選択します。
    4. 出力するをクリックします。保存の確認画面が表示された場合は、保存を選択します（claude.ai上で利用する場合）。

    補足選択した形式・用紙サイズ等はファイルごとに記憶され、次回の出力時に初期値として表示されます。記憶は利用している端末ごとです。

    7.2　形式

    形式内容主な用途
    PDF（.pdf）押印欄・集計欄・合計行を含む帳票です。「PDF」を有効にした項目を出力します。印刷、提出、保管
    Excel（.xlsx）表題・ファイル名・作成日、見出し、明細、合計行を出力します。すべての項目を出力し、数値は計算に使える数値として保存されます。集計、加工
    CSV（.csv）見出しと明細のみを出力します（合計行なし）。すべての項目を出力し、文字コードはUTF-8（BOM付き）です。他システムへの取り込み
    画像（.png）PDFと同じ帳票を画像にしたものです。複数ページの場合は、縦につないだ1枚の画像になります。メール・チャットへの貼り付け

    7.3　用紙サイズ・画質・向き（PDF・画像）

    設定選択肢
    用紙サイズA4（210×297mm）、A3（297×420mm）、B4（257×364mm）、B5（182×257mm）、A5（148×210mm）、レター（216×279mm）
    画質軽量（ファイルが小さい）、標準、高画質（印刷向け。ファイルが大きくなります）
    向き自動（列が7つ以上の場合は横向き）、縦、横

    7.4　帳票の構成（PDF・画像）

    部位内容
    表題部タイトル（既定値「備品一覧表」）、会社名・部署名（設定時のみ）、作成日
    押印欄作成・確認・承認（ファイル設定で省略できます）
    集計欄件数および合計対象項目の合計
    明細備品の一覧表（「PDF」を有効にした項目のみ）
    合計行合計対象項目の合計（二重線で区切って表示）

    複数ページにわたる場合は、2ページ目以降にも表の見出しが印字され、各ページの下部にページ番号が付されます。

    7.5　ファイル名

    「タイトル_ファイル名_出力日.拡張子」となります（例：備品一覧表_3F会議室_20261120.xlsx）。

    7.6　留意事項

    • PDF・画像の文字は画像として出力されるため、文字の選択・検索・コピーはできません。文字データが必要な場合は、ExcelまたはCSVを利用してください。
    • CSVでは、「=」「+」「-」「@」で始まる文字の先頭に「'」を付けて出力します。表計算ソフトで数式として扱われることを防ぐためです。
    • 閲覧環境によっては、Excel・CSVの保存が許可されていない場合があります（11章）。

    8項目と計算式の設定

    項目と計算式では、すべてのファイルに共通する項目と計算式を設定します。設定内容は保存をクリックした時点で反映されます。

    8.1　項目の設定

    設定内容
    順番↑↓で列の順序を変更します。一覧表および帳票の列順に反映されます。
    項目名列の見出しです。名称を変更すると、その項目を参照している計算式も自動的に更新されます。
    種類「文字」「数値」「計算式」から選択します。品名は「文字」で固定です。登録時に入力が必須となるのは品名のみで、その他の項目は省略できます。
    単位見出しに併記されます（円、個、% など）。
    小数表示する小数点以下の桁数です。
    合計有効にすると、集計欄および合計行に合計を表示します。
    PDF有効にすると、PDF・画像の帳票に列として出力します。Excel・CSVには常にすべての項目を出力します。

    項目を追加する場合は、入力する項目であれば入力項目を追加、計算式で求める項目であれば計算項目を追加をクリックします。

    8.2　計算式の記述

    • ほかの項目の値は [項目名] の形式で参照します。
    • 入力欄の下のボタンで、項目名・演算子・関数を挿入できます。
    • 入力中は計算例が表示されます。記述に誤りがある場合は理由が赤字で表示され、修正するまで保存できません。
    用途計算式の例
    合計金額[単価] × [数量]
    税込金額（税率10%、1円未満切り捨て）ROUNDDOWN([合計金額] × 1.1, 0)
    税込金額（税率の項目を参照）ROUNDDOWN([合計金額] × (1 + [税率]%), 0)
    数量10以上で単価を10%引きIF([数量] >= 10, [単価] × 0.9, [単価])

    8.3　関数・演算子一覧

    記述内容
    + − × ÷四則演算（* / も使用できます）
    %百分率（10% は 0.1）
    ROUND(値, 桁数)四捨五入。桁数0で整数、-2で百の位
    ROUNDDOWN(値, 桁数)切り捨て
    ROUNDUP(値, 桁数)切り上げ
    INT(値)小数点以下を切り捨てた整数
    MAX / MIN(値, …)最大値・最小値
    SUM(値, …)合計
    ABS(値)絶対値
    IF(条件, 真の場合, 偽の場合)条件による分岐。比較演算子は = <> < > <= >=
    AND / OR(…)すべての条件を満たす／いずれかの条件を満たす

    8.4　留意事項

    • 数値項目が未入力の場合、計算上は0として扱います。
    • 項目を削除すると、その項目に入力済みの値は表示されなくなります。
    • 互いを参照し合う計算式（AがBを、BがAを参照するなど）は保存できません。

    10データの共有（QRコード）

    この端末のデータ（すべてのファイル・備品、および項目と計算式）を1つのQRコードに変換し、別の端末へ渡すことができます。ローカル版および公開版ではデータが端末ごとに保存されるため、複数の端末で同じ台帳を利用する場合や、別の端末に控えを残す場合に使用します。

    10.1　QRコードを表示する（送る側）

    1. 画面右上のQRで共有をクリックします。この端末のデータがQRコードで表示されます。
    2. 受け取る側の端末で、表示されたQRコードを読み取ります。読み取りにくい場合は大きく表示をクリックし、画面いっぱいに表示してください。

    補足備品の件数が非常に多く1つのQRコードに収まらない場合に限り、複数のQRコードに分けて自動で切り替えて表示します。

    10.2　QRコードを読み取る（受け取る側）

    1. 受け取る側のスマートフォンの標準のカメラで、送る側のQRコードを読み取り、表示されたリンクを開きます。公開版のアプリが開き、読み取ったデータの内容が表示されます。
    2. 読み取ったデータの内容と、取り込んだ場合に上書き・削除される内容を確認し、取り込み方法を選択します。
    3. 取り込むをクリックします。

    補足本アプリのQRで共有→QRを読み取る（受け取る）からも読み取れます（アプリ内のカメラ、またはQRコードを撮影した画像を使用）。リンクから開いた場合、データはその端末の公開版に取り込まれます。

    10.3　取り込み方法

    取り込み方法内容
    受け取った内容で更新受け取ったファイルを追加します。同じファイル（以前の共有で受け取ったファイル、または共有元のファイルそのもの）がある場合は、そのファイルの備品をすべて受け取った内容に置き換えます。そのほかのファイルは変更されません。
    すべて置き換えるこの端末のファイルおよび備品をすべて削除し、受け取った内容のみとします。

    補足「項目と計算式」も受け取った内容に合わせます。「受け取った内容で更新」の場合、この端末にのみ存在する項目は残ります。

    10.4　留意事項

    • QRコードには、公開版のURLと登録内容そのものが含まれます。関係者以外に見せたり、QRコードを写した画像やリンクを共有したりしないでください。
    • 共有されるのは、その時点の内容です。共有後の変更は、改めて共有するまで相手の端末には反映されません。
    • 備品の件数が多いほどQRコードが細かくなり、読み取りにくくなります。大きく表示を使用し、カメラを近づけて写してください。
    • アプリ内のカメラの使用には、ブラウザでの許可が必要です。カメラを使用できない環境では、スマートフォンの標準のカメラ、または画像から読み取るを使用してください。

    11トラブルシューティング

    症状考えられる原因対処
    一覧に「計算エラー」と表示される0による除算など、その備品の値では計算式が成立しない表示にマウスポインターを合わせると理由が表示されます。項目と計算式で計算式を見直してください。
    出力したファイルが保存されない保存の確認画面で保存が選択されていない、または出力機能の読み込み中確認画面で保存を選択してください。「準備中です」と表示された場合は、数秒後に再度実行してください。
    「この画面ではこの形式を保存できません」と表示される閲覧環境でExcel・CSVの保存が許可されていないPDFまたは画像で出力するか、ローカル版を利用してください。
    「編集する権限がありません」と表示される閲覧のみの権限で開いている管理者に編集権限の付与を依頼してください。
    ローカル版のデータが消えたブラウザの閲覧データが削除された復元はできません。定期的に帳票を出力するか、QRコードで別の端末に控えを残してください（10章）。
    新しいファイルの色が自動で設定される判別しやすい色を自動で選択する仕様ファイル設定で任意の色に変更できます。
    カメラが起動しないブラウザでカメラの使用が許可されていない、またはカメラを使用できない環境ブラウザの設定でカメラを許可してください。許可できない場合は、QRコードを撮影した画像を画像から読み取るで読み取ってください。
    QRコードが読み取れない・スマートフォンが反応しない画面の明るさ・距離・反射、またはQRコードが細かい送る側で大きく表示をクリックし、画面を明るくして、QRコード全体が画面に収まる距離で写してください。スマートフォンの標準のカメラで読み取ると、リンクが表示されます。
    「このアプリのQRコードではありません」と表示される本アプリ以外で作成されたQRコードを読み取った送る側のQRで共有で表示したQRコードを読み取ってください。
    画面下部に「アプリの新しい版が公開されました」と表示される公開版が更新された再読み込みをクリックしてください。登録内容はそのまま残ります。
    数量の欄に入力した値が元に戻る数値以外の文字、または負の数を入力した0以上の数値を入力してください。全角数字も入力できます。
    本書を直接開きたい―本アプリのURLの末尾に #manual を付けて開くと、本書を表示した状態で起動します。
